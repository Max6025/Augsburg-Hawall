Unterdashboards

Eigenständige zusätzliche Dashboards (z.B. "Küche", "Werkstatt") mit eigenen Karten. Über eine Navigations-Karte im Editor kommst du dorthin, ein "Zurück"-Button erscheint dort automatisch.

Dashboard einspielen

Eine Datei aus „Exportieren“ – oder eine, die du selbst geschrieben hast. Die Datei erklärt ihr Format selbst: Wer sie in einen Chat wirft und „bau mir noch eine Karte für die Waschmaschine dazu“ sagt, hat damit alles beisammen, was zum Schreiben einer gültigen Datei nötig ist.
