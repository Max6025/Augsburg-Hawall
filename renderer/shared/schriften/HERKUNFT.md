# Schriften, die mitgeliefert werden

## Permanent Marker

`PermanentMarker-Regular.ttf`, Apache License 2.0 (`LICENSE-PermanentMarker.txt`).
Von Google Fonts, entworfen von Font Diner.

**Mitgeliefert und nicht nachgeladen.** Ein Wandpanel, dessen Uhr erst dann richtig aussieht,
wenn Google antwortet, ist eine Uhr mit Netzabhängigkeit — und beim ersten Start nach einem
Neustart sieht man den Wechsel der Schrift. Die Datei ist 72 kB; das ist die Sache wert.

**Die Lizenzdatei gehört dazu.** Apache 2.0 erlaubt das Mitliefern ausdrücklich und verlangt
dafür, dass die Lizenz mitreist. Wer die Schrift entfernt, entfernt beide Dateien; wer eine
hinzufügt, legt ihre Lizenz daneben und trägt sie hier ein.
