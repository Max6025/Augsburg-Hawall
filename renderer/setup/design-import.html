Design importieren

Lade eine Design-Datei (.json) hoch, um Farben und Formen/Abstände (Kartenrundung, Ränder, Schatten) auf einen Schlag zu ersetzen – für Hell- und Dunkel-Modus. Ersetzt keine Einstellungen, nur das Aussehen.

Aktuell ist ein eigenes Design aktiv.

Format der Design-Datei

Eine JSON-Datei mit diesem Aufbau (alle Farben als Text, z.B. Hex-Code oder rgba(...)): 

{
  "name": "Mein Design",
  "dark": {
    "bg": "#0a0a0b",
    "surface": "#131416",
    "panel2": "#17181b",
    "cardBorder": "rgba(255,255,255,0.06)",
    "text": "#f2f2f0",
    "muted": "#85868c"
  },
  "light": {
    "bg": "#eeebe4",
    "surface": "#faf9f5",
    "panel2": "#faf9f5",
    "cardBorder": "rgba(0,0,0,0.06)",
    "text": "#201f1c",
    "muted": "#706d66"
  },
  "cardRadius": "22px",
  "cardShadow": "0 0.6vh 1.6vh rgba(0,0,0,0.18)"
}

Die Felder cardRadius und cardShadow sind optional – ohne sie bleibt die Kartenform wie im Standard-Design.

Erweitert: Glas-/Milchglas-Effekte & komplexere Designs

Für Effekte wie "Liquid Glass" (durchscheinende, weichgezeichnete Karten) panel2/surface als halbtransparente Farbe angeben (z.B. rgba(255,255,255,0.08)) und diese zusätzlichen Felder verwenden: 

{
  "cardBlur": "22px",
  "cardSaturate": "180%",
  "cardHighlight": "rgba(255,255,255,0.45)",
  "cardHighlightSide": "rgba(255,255,255,0.18)",
  "pageBgGradient": "radial-gradient(circle at 20% 20%, #6a5acd 0%, transparent 45%), #0a0a0f",
  "extraCss": "/* beliebiges eigenes CSS, wird ganz am Ende angehängt */"
}

cardBlur/cardSaturate erzeugen den Weichzeichner-Effekt hinter den Karten (braucht einen farbigen Hintergrund zum Durchscheinen, z.B. via pageBgGradient). cardHighlight/cardHighlightSide setzen eine feine helle Lichtkante oben/links auf jeder Karte. extraCss ist ein Escape-Hatch für alles, was die anderen Felder nicht abdecken – wird roh als CSS angehängt und überschreibt bei Bedarf alles andere. Alle Felder hier sind optional und einzeln kombinierbar.
